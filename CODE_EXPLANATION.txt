1. ARCHITECTURE & PIPELINE OVERVIEW
================================================================================

The application is written in modern C++17 utilizing the OpenGL 3.3 Core Profile.
Key third-party dependencies:
  - GLAD: Dynamically queries and binds modern OpenGL function pointers from GPU driver.
  - GLFW: Handles cross-platform window creation, display modes, VSync, and keyboard/mouse events.
  - GLM (OpenGL Mathematics): Provides vector/matrix math, transformation functions,
    and perspective projection calculations aligned with GLSL conventions.

The rendering pipeline executes in two primary passes per frame:
  - Pass 1 (Shadow Depth Pass): Binds a custom 2048x2048 Framebuffer Object (FBO)
    with a depth attachment and renders the entire 3D world from the directional
    sun's point of view using an orthographic projection.
  - Pass 2 (Main Lighting Pass): Renders to the default framebuffer with Blinn-Phong
    shading, Half-Lambert wrap diffuse, soft 3x3 PCF shadow testing, procedural
    dune ripple micro-textures, quartz sand sparkles, exponential distance fog,
    and alpha-blended blowing sand dust billboards.

2. PROCEDURAL MESH GENERATION (NO .OBJ FILES)
================================================================================

Rather than relying on pre-baked external asset files (.obj), every geometry in
Arrakis is constructed directly in system memory using mathematical formulas and
uploaded into GPU Vertex Array Objects (VAOs) and Vertex Buffer Objects (VBOs):

- Vertex Memory Layout (struct Vertex):
    Position : vec3 (12 bytes, layout location 0)
    Normal   : vec3 (12 bytes, layout location 1)
    UV Coord : vec2 (8 bytes,  layout location 2)
  Total stride per vertex: 32 bytes (optimally cache-aligned).

- Primitives Implemented:
  1. createCube():
     Generates 24 distinct vertices across 6 faces (each face has its own constant
     surface normal perpendicular to the face to ensure sharp shading edges).
     Indexed by 36 triangle indices (6 faces x 2 triangles x 3 indices).

  2. createCylinder(slices = 24):
     Calculates smooth vertices around a parametric unit circle:
       x = r * cos(theta), z = r * sin(theta)
     Normals on the side cylinder wall point radially outwards (x, 0, z), producing
     smooth cylindrical shading. Top and bottom caps feature independent planar
     normals pointing straight up (+Y) and down (-Y).

  3. createSphere(lats = 16, lons = 24):
     Constructs a UV sphere via spherical polar coordinates:
       x = r * sin(theta) * cos(phi)
       y = r * cos(theta)
       z = r * sin(theta) * sin(phi)
     Every vertex normal is simply its normalized position vector, producing smooth
     specular curvature highlights for canopies, pressure heads, and searchlights.

  4. createWingBlade():
     Generates an aerodynamic dragonfly aerofoil wing. Tapers from root chord (1.0)
     to a fine tip chord (0.22) across an 8-segment span, with a corresponding
     reduction in blade thickness. Used for the 8 wings of the movie ornithopter.

  5. createDuneTerrain(140x140 grid):
     Generates a continuous, seamless grid spanning 700x700 world units.
     Computes elevation y = getDuneHeight(x, z) and analytical normal vectors
     getDuneNormal(x, z) for every vertex.

  6. createQuad():
     A 2-triangle planar quad used for billboarded dust particles and fullscreen skybox.

3. DUNE HEIGHTFIELD ANALYTICAL SURFACE & TERRAIN NORMALS
================================================================================

The sand dunes are governed by an analytical height function:
  f(x, z) = 14.0 * sin(0.009*x + 0.004*z)
          +  9.5 * cos(0.004*x - 0.012*z)
          +  5.0 * (1.0 - |sin(0.028*x + 0.016*z)|)^2
          +  1.8 * sin(0.065*x + 0.038*z) - 4.0

Mathematical Explanation:
  - The first two terms produce monumental rolling dune swells (barchan dunes).
  - The third term: (1.0 - |sin(...)|)^2 creates sharp, asymmetric ridge crests
    characteristic of wind-sculpted sand dunes where sand accumulates on the slipface.
  - The fourth term adds gentle undulations.

Analytical Surface Normals (Finite Differences):
  To calculate accurate surface normals without artifacts:
    dh/dx approx (h(x+eps, z) - h(x-eps, z)) / (2*eps)
    dh/dz approx (h(x, z+eps) - h(x, z-eps)) / (2*eps)
    Normal = normalize( -dh/dx, 1.0, -dh/dz )
  This guarantees continuous, accurate shading normals across the entire terrain grid.

Vehicle Surface Adherence:
  The Spice Harvester, Spice Tanks, and Rocks sample getDuneHeight(x, z) so they
  rest naturally on the sloping sand dunes without clipping or floating.

4. ATMOSPHERIC WIND & BLOWING SAND PARTICLE SYSTEM
================================================================================

Global Wind Vector:
  WIND_DIR = normalize(vec3(-0.92, -0.04, 0.38))
  WIND_BASE_SPEED = 18.0 units/sec

Particle Physics & Dynamics:
  - 2,400 persistent particles are managed in a dynamic vector.
  - Each particle has position, velocity, life, maxLife, size, and alpha.
  - A dynamic wind gust multiplier `1.0 + 0.35 * sin(time * 1.8)` modulates particle
    drift velocity in real time.
  - Terrain collision detection: If a particle dips below `getDuneHeight(x, z) + 0.2`,
    it bounces gently upwards, hugging the dune contours.
  - Proximity Wrapping: When a particle's life expires or it drifts farther than
    130 units from the player, it is recycled upwind of the camera.
  - Harvester Dust Plume: 25% of all recycled particles spawn directly behind the
    massive crawler tracks of the Spice Harvester with higher initial alpha and
    vertical turbulence, simulating plumes of kicked-up spice sand.

Particle Shading:
  - Billboards are oriented towards the camera using the camera's Right and Up vectors:
      worldPos = particlePos + camRight * (pos.x * size) + camUp * (pos.y * size)
  - The fragment shader discards fragments beyond radius 0.5 and computes a smooth
    radial opacity falloff: `smoothstep(0.5, 0.0, dist) * alpha`.
  - Rendered with additive-alpha blending (GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA)
    with depth writes disabled (glDepthMask GL_FALSE) to prevent self-occlusion artifacts.

5. SHADERS & LIGHTING PIPELINE
================================================================================

5.1 Blinn-Phong + Half-Lambert Sand Wrap Lighting:
  Standard Lambertian diffuse produces harsh, unnatural black shadow transitions
  on powdery surfaces like desert sand. Arrakis solves this with Half-Lambert wrap:
    diffuseFactor = (dot(N, L) + 0.35) / 1.35;
  This allows sunlight to softly diffuse into micro-crevices on the sand surface.

  Blinn-Phong Specular uses the half-angle vector H = normalize(L + V):
    specularFactor = pow(max(dot(N, H), 0.0), shininess);
  Metallic surfaces (cockpit frame, engine pods) utilize high shininess (64-128),
  while sand uses a low, soft sheen (16).

5.2 Procedural Dune Sand Micro-Shading:
  When rendering the terrain (`isSand == 1`), the fragment shader computes:
  - Wind Ripples: Two sinusoidal wave harmonics aligned with the wind direction
    modulate the base albedo subtly:
      ripple1 = sin(pos.x * 2.2 + pos.z * 1.4) * 0.5 + 0.5;
      ripple2 = sin(pos.x * 0.8 - pos.z * 1.9) * 0.5 + 0.5;
  - Slope-Dependent Color Gradient:
      slope = clamp(dot(N, vec3(0, 1, 0)), 0.0, 1.0);
    Crests facing upwards receive sun-bleached golden sand (COL_DUNE_SAND * 1.15),
    while steep slopes receive deeper reddish-ochre tones.
  - Quartz Sand Glints: High-frequency pseudo-random specular flashes simulate
    glinting quartz crystals in the desert sun:
      sparkle = pow(max(dot(N, H), 0.0), 120.0);

5.3 Percentage-Closer Filtered (PCF) Shadow Mapping:
  - Pass 1 generates a 2048x2048 floating point depth map.
  - Slope-scaled bias (`glPolygonOffset(2.5, 4.0)`) prevents shadow acne.
  - In Pass 2, a 3x3 sampling kernel queries 9 neighboring depth texels:
      for(int x = -1; x <= 1; ++x)
        for(int y = -1; y <= 1; ++y)
          shadow += (currentDepth - bias > sampleDepth(uv + offset)) ? 1.0 : 0.0;
      shadow /= 9.0;
    This produces soft, realistic shadow penumbras across the undulating dunes.

5.4 Atmospheric Desert Fog:
  An exponential squared distance fog blends the scene into a warm golden horizon:
    dist = length(viewPos - FragPos);
    fogFactor = 1.0 - exp(-pow(dist * fogDensity, 2.0));
    finalColor = mix(litColor, fogColor, fogFactor);

6. MOVIE-ACCURATE 3D OBJECT MODELING

6.1 Atreides Ornithopter:
  - Fuselage: Elongated aerodynamic dragonfly pod composed of smooth ellipsoids and
    tapered forward cylinders, culminating in a forward sensor probe.
  - Stealth Cockpit: Faceted canopy with dark tinted armored glass (specular 0.9,

  - Turbine Intakes & Reheat Jets: Twin dorsal air scoops and twin flank turbine

    when the pilot presses Left Shift).
  - Tandem 8-Blade Dragonfly Wings:
    - 4 wings on starboard (+X) and 4 wings on port (-X).
    - Upper pair and lower pair oscillate in anti-phase (phase offset of 0.75*pi).
    - Features pitch angle-of-attack twisting during each up/down stroke.
    - Flap frequency dynamically increases as flight speed and boost increase.

6.2 Massive Industrial Spice Harvester:
  - Quad Heavy Crawler Tracks: 4 separate pontoon units with heavy armor skirts,
    each housing drive sprockets and road wheels.
  - Harvesting Cutter Drum: Massive forward rotating cylinder with crusher teeth
    and a glowing cinnamon Melange suction intake.
  - Refinery Superstructure: Multi-tiered processing hopper, bridge cabin with
    panoramic viewports, dual forward floodlights, and twin exhaust smokestacks
    venting pulsing spice vapor.
  - Autonomous Movement: Crawls continuously along the sand dunes at 3.2 units/sec,
    tilting dynamically to match the slope of the terrain underneath.

6.3 Movie Spice Pressure Tanks:
  - Cylindrical Pressure Vessel: Horizontal cylinder with hemispherical domed endcaps
    and reinforcing weld seams.
  - Transport Cradle: Heavy industrial skid base with diagonal I-beam trusses and

  - Illuminated Spice Sight Tube: A glowing vertical liquid level gauge emitting

  - Dynamic Deployment: Spawns behind the Harvester every 24 units of travel, resting
    directly on the dune surface.

6.4 Desert Rock Yardangs:
  - Multi-tier angular boulder spires stacked at contrasting angles with alternating
    sedimentary strata colors (iron-red sandstone and desert varnish).

7. FLIGHT KINEMATICS & CINEMATIC CHASE CAMERA
================================================================================

Flight Kinematics:
  - Velocity Vector: Controlled by forward heading yaw:
      fwd = (-sin(yaw), 0, -cos(yaw))
      pos += fwd * (speed * dt)
  - Aerodynamic Banking: When steering left (A) or right (D), the ornithopter
    smoothly rolls into the turn (target roll of +/-32 degrees).
  - Pitch Dynamics: Ascending (Q) or descending (E) tilts the fuselage nose up/down.
  - Ground Avoidance: Enforces a minimum flight altitude above the dune surface.

Camera System:
  - View Modes (Toggle with C key):
    1. Cinematic Chase (Mode 0): Floats 24 units above and behind the ornithopter.
    2. Cockpit Close (Mode 1): Close behind the canopy for high-speed perspective.
    3. Overhead Tactical (Mode 2): High above, surveying the harvester and dunes.
  - Spring Damping: Both camera position and look target use `glm::mix` exponential
    smoothing to eliminate jarring motions.
  - Free Orbit: Arrow keys allow 360-degree orbit around the ornithopter in any mode.

================================================================================
8. FRAME RENDERING EXECUTION FLOW
================================================================================

Each frame in the render loop executes the following stages:
  1. Time delta calculation (`dt = curTime - prevTime`).
  2. Input processing & flight physics integration (speed, banking, pitch, heading).
  3. Harvester progression & dynamic spice tank spawning.
  4. Particle update (wind drift, gusts, terrain collision, recycling).
  5. Camera smoothing & matrix construction (`glm::lookAt`, `glm::perspective`).
  6. PASS 1 (Shadow Depth Pass):
     - Bind `g_shadowFBO` (2048x2048).
     - Clear depth buffer.
     - Enable `GL_POLYGON_OFFSET_FILL`.
     - Render full scene with `g_progShadow`.
  7. PASS 2 (Main Screen Render):
     - Bind default screen framebuffer (native resolution).
     - Clear color and depth.
     - Render atmospheric skybox quad with sun disk and corona.
     - Render full 3D scene with `g_progScene`, shadow map, Blinn-Phong, and fog.
     - Render 2,400 blowing sand particles with `g_progParticle` (alpha blended).
  8. Swap GLFW buffers and poll window events.

================================================================================
9. RESOURCE MANAGEMENT & CLEANUP
================================================================================

Upon exit (ESC key):
  - All shader programs are deleted (`glDeleteProgram`).
  - Shadow FBO and depth texture are freed (`glDeleteFramebuffers`, `glDeleteTextures`).
  - GLFW window and context are destroyed (`glfwDestroyWindow`, `glfwTerminate`).
